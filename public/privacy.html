2. Log Data, Edge Telemetry & Analytics

Our edge infrastructure (hosted via AWS CloudFront global edge locations) automatically logs standard, non-personally identifiable technical request data. This includes:

  • Browser user-agent, operating system, and language preferences.
  • Date and timestamp of edge network requests.
  • Approximate geographic region (country and city code derived at the CDN edge).
  • HTTP status codes, referring URLs, and resource latency.

This data is used solely to maintain uptime, monitor latency, detect DDoS or security incidents, and optimize site delivery. It is never linked to individual personal identities.
